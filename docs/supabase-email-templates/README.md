# Supabase Email Templates (6 Auth Templates)

Thư mục này chứa 6 file template HTML để paste vào Supabase:

1. `01-confirm-sign-up.html`
2. `02-invite-user.html`
3. `03-magic-link.html`
4. `04-change-email-address.html`
5. `05-reset-password.html`
6. `06-reauthentication.html`

Gợi ý Subject:

1. Confirm sign up: `Xác nhận tài khoản Timeline Teky Hoàng Mai`
2. Invite user: `Bạn được mời tham gia Timeline Teky Hoàng Mai`
3. Magic link: `Link đăng nhập của bạn - Timeline Teky Hoàng Mai`
4. Change email address: `Xác nhận thay đổi email`
5. Reset password: `Đặt lại mật khẩu tài khoản của bạn`
6. Reauthentication: `Mã xác minh xác thực lại`
